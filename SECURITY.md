# Security

Review stores GitHub credentials and AI provider keys on your machine and sends code to the AI providers you connect. If you find a way to leak those, run code through a repository or diff, or get around the IPC checks, please report it privately.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/hamedghaderi/review/security/advisories/new). Please don't open a public issue. Include the version, your OS and the steps to reproduce.

You'll get a reply within a week. Fixes go into the next release, and the advisory is published once that release is out.

## Supported versions

Only the latest release gets security fixes.
