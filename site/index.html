Code review that stays on your machine.

Review is a desktop app for reading Git branches and GitHub pull requests, leaving comments, and publishing them when you're ready. Add an AI reviewer with your own key, or run a local model. Or skip AI entirely.

Download Review All platforms

Free and open source · MIT · macOS, Windows, Linux

Browse branches and pull requests

Local branches, remotes and GitHub pull requests in one list. Pick a branch and a base, and Review compares it from the merge base. Each review is pinned to exact commits, so the diff doesn't move under you when someone pushes.

Press ⌘P to go anywhere

Quick open lists the pull requests waiting on you, your recent reviews and your branches. Type to search, Enter to open the review, ⌘K for more actions. Every list in the app works from the keyboard.

Bring your own model, or none

Manual review works without any AI set up. When you want a second reader, connect OpenAI, Anthropic, Google Gemini, OpenRouter, any OpenAI-compatible endpoint, or a local model in Ollama or LM Studio. Keys are encrypted with your system keychain.

AI reviewers can call tools from MCP servers for context the repository can't give, like the ticket behind a change. Their findings become draft comments you keep, edit or dismiss.

The details

Publishing
Nothing goes to GitHub until you publish. Comments land in your pending review, and you submit it.
Your data
Reviews are saved on your computer. Your code is only sent anywhere when you run an AI review with a cloud provider.
Requirements
Git on your PATH. The GitHub CLI is optional; a token works too.
Platforms
macOS (Apple silicon and Intel), Windows 10 and 11, Linux (AppImage).
License
MIT. Read it, fork it, change it.

Run it from source

Needs Node 22.12 or later and Git. npm test runs the suite against temporary repositories.

Read the README 
$ git clone https://github.com/hamedghaderi/review.git
$ cd review
$ npm install
$ npm run dev

Opening it the first time

The installers aren't signed with an Apple or Microsoft certificate yet, so your system asks once:

  • macOS: open Review, then go to System Settings → Privacy & Security and click Open Anyway.
  • Windows: on the SmartScreen warning, click More info, then Run anyway.
  • Linux: make the file executable with chmod +x Review-*.AppImage and run it.

Older versions and release notes are on the releases page.
